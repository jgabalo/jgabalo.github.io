## Setup

1. Clone this repository
2. Replace placeholder content with your own information:
   - Update personal details in `index.html`
   - Add your profile picture to `assets/profile.jpg`
   - Add project images to `assets/` folder
   - Update social media links
   - Customize colors in `styles.css` (root variables)

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
  --primary-color: #0d6efd;
  --dark-bg: #1a1a2e;
  --darker-bg: #16213e;
}
```

### Content
All content is in `index.html`. Simply find the relevant section and update:
- Personal information
- Skills and percentages
- Projects
- Experience
- Contact details

### Images
Add your images to the `assets/` folder:
- `profile.jpg` - Your profile picture
- `project1.jpg`, `project2.jpg`, `project3.jpg` - Project screenshots

## Deployment

### GitHub Pages
1. Push your code to GitHub
2. Go to repository Settings ? Pages
3. Select main branch as source
4. Your site will be available at `https://yourusername.github.io`
