# John Guiller Balo — Engineering portfolio

Static, responsive portfolio based on the supplied professional résumé. No build, backend, tracking, external runtime dependencies or secrets required.

## Run locally

Serve the repository root with a static HTTP server (for example, `python -m http.server 8000`) and visit http://localhost:8000. The public-safe printable résumé is at resume.html.

## Deploy

After review and merge, configure GitHub Pages to deploy from main / root. The default project URL is normally https://jgabalo.github.io/neoraltech.github.io/. Verify the actual Pages configuration before sharing the URL.

## Review checklist

- Check keyboard navigation, focus indicators and theme persistence.
- Check mobile widths, reduced motion, project filters and print/PDF layout.
- Review public case study wording and career availability before publishing.
- Verify GitHub and LinkedIn links; confirm Pages deployment.

Client case studies are sanitised. Agentic triage is a prototype, Agent Utopia is a concept, and repository exploration does not imply upstream authorship. Phone, residential suburb and personal email are excluded. Old template documentation and assets remain in the repository for reference.
