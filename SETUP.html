?? Portfolio Setup Helper

Follow these steps to customize your portfolio website

1

Replace Personal Information

Open index.html and find & replace:

Find: "Your Name"
Replace with: Your actual name
Appears in: sidebar, navbar, hero section, footer
Find: "Developer | Designer"
Replace with: Your professional title
Example: "Full Stack Developer" or "UI/UX Designer"
Find: "your.email@example.com"
Replace with: Your email address
Appears in: sidebar, about section, contact section
2

Update Social Links

In index.html, update these URLs:

GitHub: Change github.com/yourusername
Line ~36: href="https://github.com/yourusername"
LinkedIn: Change linkedin.com/in/yourusername
Line ~39: href="https://linkedin.com/in/yourusername"
3

Add Your Images

Replace placeholder images in the assets/ folder:

profile.jpg - Your professional headshot (300x300px recommended)
project1.jpg - First project screenshot (800x600px)
project2.jpg - Second project screenshot (800x600px)
project3.jpg - Third project screenshot (800x600px)
?? Tip: Use tools like TinyPNG to compress images for faster loading
4

Customize About Section

Update your personal information (lines 89-115):

Write your personal story and introduction
Update age, location, education, email
5

Update Skills

Modify your skills and proficiency levels (lines 130-230):

Change skill names to match your expertise
Adjust percentages: style="width: 85%"
Add or remove skill categories
6

Add Your Projects

Replace placeholder projects (lines 240-310):

Update project titles and descriptions
Change technology badges
Add real GitHub and demo links
7

Update Experience

Add your work history (lines 320-420):

Update job titles, companies, dates
List your responsibilities and achievements
Add or remove experience entries
8

Deploy to GitHub Pages

Push your changes and enable GitHub Pages:

git add .
git commit -m "Customize portfolio"
git push origin main

Then go to Settings ? Pages ? Select 'main' branch ? Save
