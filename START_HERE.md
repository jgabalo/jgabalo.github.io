## Next Steps (5 minutes)

### 1. Open Setup Helper
Double-click `SETUP.html` to see a visual checklist of what to customize.

### 2. Edit Your Info
Open `index.html` in a text editor and replace:
- "Your Name" ? Your actual name
- "your.email@example.com" ? Your email
- "yourusername" ? Your GitHub/LinkedIn username

### 3. Add Your Photos
Replace these files in the `assets/` folder:
- `profile.jpg` - Your headshot
- `project1.jpg`, `project2.jpg`, `project3.jpg` - Project screenshots

### 4. Test Locally
Double-click `index.html` to preview your site in a browser.

### 5. Deploy
```bash
git add .
git commit -m "Setup my portfolio"
git push origin main
```

Then enable GitHub Pages in your repository settings.

## Customization Quick Reference

### Change Colors
Edit `styles.css` line 2:
```css
--primary-color: #0d6efd; /* Your brand color */
```

### Update Skills
Find the skills section in `index.html` (line ~130) and update:
- Skill names
- Percentages: `style="width: 85%"`

### Add Projects
Copy and paste a project card (lines ~240-280) and customize:
- Title and description
- Technology badges
- GitHub and demo links
- Image path

### Modify Experience
Edit timeline items (lines ~320-420):
- Job titles and dates
- Company names
- Responsibilities

## Tips for Success

### ?? Content
